# TaskFlow

## 1. Descripción
TaskFlow es una aplicación web intuitiva diseñada para facilitar la administración y el seguimiento de tareas dentro de un entorno de trabajo colaborativo. Permite a los usuarios organizar sus actividades pendientes y optimizar la productividad del equipo.

### 1.1 Objetivo
El objetivo principal de esta aplicación es proporcionar una herramienta centralizada que permita a los miembros de un equipo registrar, asignar y monitorear el progreso de sus tareas diarias de manera clara y eficiente.

---

## 2. Funcionalidades
* **Gestión de tareas:** Permite registrar nuevas tareas, editar los detalles existentes y eliminarlas cuando sea necesario.
* **Asignación de miembros:** Opción para vincular a usuarios específicos del equipo a tareas determinadas.
* **Seguimiento de estado:** Clasificación rápida de actividades en estados como pendientes, en proceso o completadas.
* **Filtros y búsquedas:** Búsqueda rápida de tareas por estado o usuario asignado.

---

## 3. Tecnologías utilizadas
* **Frontend:** HTML5, CSS3 y JavaScript (ES6+).
* **Backend:** Node.js con Express.
* **Base de datos:** MySQL.
* **Control de versiones:** Git y GitHub.
