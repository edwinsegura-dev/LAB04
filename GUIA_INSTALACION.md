# Guía de instalación de Python

## 1. Introducción

### 1.1 ¿Qué es Python?

Python es un lenguaje de programación utilizado para desarrollar diferentes tipos de aplicaciones.

### 1.2 ¿Para qué se utiliza?

Python puede utilizarse en:

- Desarrollo web.
- Ciencia de datos.
- Inteligencia Artificial.
- Automatización de tareas.

## 2. Requisitos

Para instalar Python se requiere:

- Una computadora.
- Acceso a Internet.
- Sistema operativo compatible.

## 3. Proceso de instalación

### 3.1 Descargar Python

1. Ingresar al sitio oficial.
2. Seleccionar la versión correspondiente.
3. Descargar el instalador.

[Visitar sitio oficial](https://www.python.org/)

[Consultar documentación](https://docs.python.org/)

### 3.2 Ejecutar la instalación

Ejecute el instalador descargado y siga los pasos indicados.

![Logo de Python](imagen-python.png)

### 3.3 Verificar la instalación

Abra una terminal y ejecute:

```bash
python --version
